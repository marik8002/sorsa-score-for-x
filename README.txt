Sorsa Score for X
=================

Sorsa Score displays Sorsa scores beside account handles on x.com and
twitter.com, including profiles, posts, account lists, and hover cards. Sign in
to Sorsa in the same browser first. Clicking a score opens that Sorsa profile.
With Sorsa Plus, it can show bot follower estimates on X profile pages.
While X is open, the extension quietly rechecks the Sorsa session every ten
minutes. If Sorsa expires the session, sign in again to continue.
Refreshing bots may briefly open a Sorsa tab.

Privacy
-------
The extension reads only account handles displayed in X identity areas.
It does not read or transmit post content.
The browser sends your Sorsa session cookies to Sorsa with profile requests.
The extension does not read or store the cookies, passwords, or API keys.

Cache
-----
Confirmed scores, last bot estimates, and the last confirmed Plus status are
stored locally. Scores expire after 24 hours. Use "Clear score cache" in the
popup to request fresh values.
